# Website Architecture – Personal Expenses Tracker 

### 1. How many pages and what are they?
The website consists of following pages:

- **Sign Up, Login, and Logout:** Sign Up allows users to create an account, Login provides access to their account, and Logout allows users to exit their account.
- **Dashboard:** Displays an overview of the user's financial activities.
- **Add Expenses:** Allows users to add new expenses with relevant details.
- **View Expenses:** Shows the list of expenses recorded by the user.
- **Income:** Displays and manages the user's income records.
- **Categories:** Organizes expenses into different categories, such as food, transport, and bills.
- **Monthly Reports:** Displays monthly summaries of income and expenses.

### 2. How does navigation work?
On desktop, the website uses a horizontal navigation bar to navigate between different pages or sections. On mobile devices, a responsive hamburger menu is used to make navigation easier and keep the layout clean.

### 3. How did you use CSS?
CSS is used to style the website, including colors, fonts, spacing, buttons, cards, and layout. Media queries are used to make the website responsive across different screen sizes, including desktops, tablets, and mobile devices.
